# Christmas Planner by @itsgemma__

A free Christmas present planner: everyone you're buying for, a budget each, and a tick when a present is ordered and when it arrives. Works on phone and laptop.

Live at https://itsgemma-planner.netlify.app

Built for Netlify: the page is in `public/`, the sign-up, sign-in and saving jobs are in `netlify/functions/`, and each person's planner is stored in Netlify Blobs. No keys or customer data live in this repository. Run the checks with `npm install && npm test`.
